# Accessible Contact Form

A responsive contact form built using HTML, CSS, and JavaScript, featuring form validation and an animated toast notification.

## Features
- Responsive layout using CSS Grid.
- Required field validation.
- Accessible labels and keyboard navigation.
- Screen reader announcements using ARIA live regions.
- Animated bottom-center toast notification.

## Technologies Used
- HTML
- CSS
- JavaScript

## Approach
Semantic HTML provides the form structure, CSS handles styling and animations, and JavaScript manages form submission and toast notifications.

## Project Files
- `index.html` — Form structure.
- `styles.css` — Styling and animations.
- `scripts.js` — Form handling and toast notifications.

## Limitations
The form currently demonstrates front-end functionality and does not send data to a server.
